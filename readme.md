
# Mern - CRUD






## Run Locally

Clone the project

```bash
  git clone https://github.com/BibekRai44/Mern-CRUD
```

Go to the project directory

```bash
  cd Mern-CRUD
```


Install dependencies

```bash
  npm run build
```
Setup .env file

```bash
    MONGO_URI=your_mongo_uri
    PORT=5000
```

Start the server

```bash
  npm run start
```
